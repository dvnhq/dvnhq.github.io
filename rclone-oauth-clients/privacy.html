Privacy policy – dvnhq rclone

Last updated: 2026-10-26

dvnhq rclone is an OAuth client used solely by its owner to run rclone against the owner's own Google Drive account.

Data accessed

With the owner's consent, rclone accesses Google Drive files and metadata in order to list, upload, download, and synchronise files at the owner's direction.

Data storage and sharing

  • No data is collected by, sent to, or stored on any server operated by dvnhq.
  • OAuth tokens are stored only in the local rclone configuration on the owner's own machines.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
